# AutoCut Studio architecture

AutoCut Studio 1.1 keeps the CEP entrypoint deliberately thin. `js/main.js`
contains the application core and uses `PremiereBridge` for all host calls.
`jsx/host.jsx` is generated by concatenating the ES3-compatible domain
implementation and `AutoCutStudio.invoke` dispatcher.

The analyzer and installer are Rust workspace crates. Native color processing
is a standalone C++ library linked by the Premiere effect and by its test
executable. The application core does not depend on CEP APIs, so a future UXP
adapter can reuse it without changing marker, motion, or analyzer logic.
